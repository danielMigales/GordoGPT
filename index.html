04 / DATOS

Gestionar historial

Puedes importar un JSON con el formato del README, descargar una copia o exportar el historial como CSV. Las importaciones se guardan en este navegador cuando el almacenamiento local está disponible; no se envían a un servidor.

GordoGPT es un proyecto estadístico experimental e independiente. No predice resultados con certeza ni está afiliado a SELAE.
